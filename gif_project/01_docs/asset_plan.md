# GitHub 프로필 픽셀아트 GIF 배너 자산 계획

## 1. 프로젝트 목표

`00_reference/master_reference.png`를 최종 정답으로 고정하고, 그 장면을 좌표가 보존된 소형 애니메이션 자산으로 역설계한다. 새로운 장면을 재창작하지 않는다. 모든 결과는 원본과 합쳤을 때 동일한 작품처럼 보여야 한다.

기준 정보:

- 기준 파일: `00_reference/master_reference.png`
- 캔버스: 1913 × 822 px
- 좌표 원점: 원본 좌상단 `(0, 0)`
- SHA-256: `BB10049AF423DAD6861B660548BE97E86B30EC1BEE385AB41E135F801CB6CAD1`
- 기준 우선순위: 구도와 좌표 → 실루엣 → 픽셀 밀도 → 팔레트/조명 → 세부 묘사 → 애니메이션

## 2. 최종 결과물

- 원본과 같은 1913 × 822 비율과 장면 구성을 유지한 GitHub 프로필용 루프 GIF 배너
- 고정 배경 위에 승인된 투명 자산만 원본 좌표로 합성
- 영웅과 용의 보행, 종이/마법 흐름, 랜턴 광량 등 제한된 국소 애니메이션
- 하단 영문 배너와 상단 한국어 말풍선의 가독성 및 위치 보존
- GIF 변환 전 무손실 프레임 시퀀스와 합성 미리보기 보존

## 3. 원본 장면 해석

장면은 보랏빛 석양의 판타지 작업 공간이다. 좌측의 거대한 나무와 매달린 랜턴, 중앙의 영웅과 작은 보라색 용, 우측으로 흐르는 문서 자동화 마법, 우측 사무용 소품과 완료 표지판, 화면 하단의 암반 플랫폼 및 영문 배너가 한 화면에 결합되어 있다.

핵심 시선 흐름은 `용 → 영웅/지팡이 → 빛의 곡선과 종이 → 완료된 폴더/체크리스트 → 정리 완료 표지판`이다. 애니메이션은 이 흐름을 강화해야 하며 장면 전체를 흔들거나 재배치해서는 안 된다.

## 4. 스타일 원칙

- 원본의 짙은 자주/남보라 그림자와 분홍·복숭아색 석양, 청록 마법광의 팔레트를 유지한다.
- 픽셀 경계는 선명하게 유지한다. 확대/축소 시 최근접 보간만 사용한다.
- 안티앨리어싱, 벡터형 매끈한 윤곽, 사진 질감, 과도한 블룸을 새로 넣지 않는다.
- 광원은 석양의 분홍빛, 랜턴의 주황빛, 마법의 청록빛이라는 세 계통을 유지한다.
- 원근은 좌측 거목과 근경 플랫폼, 중경 캐릭터/가구, 원경 도시와 구름의 깊이를 보존한다.
- 오브젝트의 좌표, 크기, 겹침 순서와 여백은 원본을 기준으로 한다.
- 루프는 눈에 띄는 점프가 없어야 하며, 고정 요소는 프레임 사이에서 단 1 px도 흔들리지 않아야 한다.

## 5. 작업 원칙

1. 한 번에 하나의 자산만 제작한다.
2. 자산 파일과 동시에 `04_previews/<asset>_composite.png` 또는 짧은 검수용 루프를 만든다.
3. 미리보기는 반드시 1913 × 822 원본 좌표에 배치한다. 자산만 잘라 본 결과로 승인하지 않는다.
4. 승인 전 자산은 다음 자산의 기준이나 최종 합성에 사용하지 않는다.
5. 승인 상태는 `candidate → review → approved`로 관리한다.
6. 불합격 자산은 억지 보정하거나 다른 자산의 기반으로 삼지 않고 `99_deprecated/`로 이동한다.
7. 한 자산의 좌표와 프레임 등록점(anchor)은 모든 프레임에서 동일해야 한다.
8. 애니메이션이 없는 요소를 억지로 분리하거나 움직이지 않는다.
9. 최종 정답과의 유사도가 화려한 움직임보다 우선한다.
10. 현재 단계에서는 자산 및 GIF를 생성하지 않는다.

## 6. 사용 금지 자산 유형

다음은 기존 결과물이 발견되더라도 승인 없이 사용하지 않는다.

- 잘못 분리되거나 깨진 `sky`, `sky_far`, `foreground`, `tree`, `ground`
- 전체 하늘, 전체 전경, 전체 나무, 전체 지면을 통째로 움직이는 대형 레이어
- `speech_text_sheet`, `star_twinkle` 계열의 재생성 또는 승계
- 원본과 다른 장면 해석으로 생성된 배경/캐릭터
- 리샘플링으로 픽셀이 번진 이미지, 반투명 테두리 오염이 있는 스프라이트
- 원본 좌표 합성 검증이 없는 단독 자산
- 출처와 버전, 승인 상태를 확인할 수 없는 파일

## 9. 자산별 검수 기준

### 공통 검수

- 원본 좌표에서 중심, 바닥선, 겹침 순서가 일치하는가
- 실루엣과 점유 면적이 원본과 같은가
- 확대 시 픽셀 경계가 선명하고 반투명 오염이 없는가
- 원본의 자주/분홍/청록/주황 조명 관계를 유지하는가
- 프레임마다 등록점이 흔들리지 않는가
- 정지 프레임만 보아도 원본의 같은 오브젝트로 인식되는가
- 루프 시작/끝의 위치, 광량, 자세가 자연스럽게 연결되는가

| `clouds_layer_A/B` | 이동 전후에도 원본 구름 실루엣과 석양 그라데이션을 훼손하지 않음. 어색하면 애니메이션을 폐기하고 고정 배경에 유지 |
| `final_composite_preview` | 원본과 빠르게 교차 표시했을 때 구도 점프가 없고, 전체 루프에서 고정물 떨림·색상 깜빡임·투명 경계가 없음 |

## 10. 기존 자산 분류

현재 작업 폴더와 접근 가능한 Codex 작업영역을 조사했으나 승계 가능한 기존 자산 파일은 발견되지 않았다.

### 재사용 가능

- 없음
- 추후 후보가 발견되더라도 원본 좌표 합성 검수를 통과한 자산만 `approved`로 승계한다.

### 참고 전용

- `00_reference/master_reference.png`: 최종 정답 및 모든 비교의 기준. 애니메이션 자산으로 직접 변형하지 않는다.
- 추후 발견되는 이전 작업 중 원본과 유사하지만 좌표/투명 경계/프레임 등록을 검증하지 못한 파일

### 폐기 또는 사용 금지

- 기존의 잘못 분리된 `sky`, `sky_far`, `foreground`, `tree`, `ground`
- `star`, `star_twinkle`, `speech_text`, `speech_text_sheet` 계열
- 출처 불명, 중복, 좌표 미검증, 원본과 다른 장면 해석의 자산

현재 실제 폐기 대상 파일은 작업 폴더에 없으므로 파일 이동이나 삭제는 수행하지 않았다.
