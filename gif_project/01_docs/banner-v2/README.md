# 에반과 미르의 자동화 마법 · 프로필 배너 V2

원본의 보랏빛 노을과 “반복은 내가 처리할게!”라는 대사를 살려, 에반과 미르가 마법으로 서류를 정리하는 픽셀 아트 배너를 만든다. 첫 작업은 **미르가 벚꽃잎을 올려다보고 에반의 지팡이가 빛나는 한 컷**이다. 이 브랜치에는 V2 제작 계획을 담았다. 새 원화, 모바일 배너, 인터랙티브 페이지는 앞으로 만들 작업이다.

## 집에서 시작하기

Git이 설치된 컴퓨터에서 다음 명령으로 인계 브랜치를 받는다.

```sh
git clone --branch codex/banner-v2-handoff https://github.com/koeje1/github-profile-banner-animation.git
cd github-profile-banner-animation
```

먼저 [원본 그림](../../00_reference/master_reference.png)과 [기존 개발 프리뷰](../../05_exports/github_profile_banner_dev_preview.gif)를 나란히 본다. 구현 기준은 `e6129a3`이다. 기존 렌더러는 1913×822 화면에 5.04초 루프를 만들며, 에반은 6프레임, 미르는 4프레임이다. 배경, 캐릭터, 그림자, 마법, 종이, 글자가 분리되어 있어 V2에서도 활용할 수 있다. ## 첫 원화에서 잡을 장면

- **에반과 미르** — 에반의 손등과 망토 끝에 지팡이의 푸른빛이 닿는다. 미르는 주둥이와 뿔의 윤곽이 배경에서 또렷하게 보이고, 눈이 먼저 벚꽃잎을 따라간다. 이 컷이 잡히면 좌우와 위쪽을 보는 미르의 표정을 같은 비율로 그린다.
- **마법과 서류** — 종이 한 장의 출발점과 도착점이 보이게 한다. 보석이 빛나고, 종이가 그 궤적을 따라 접혀 폴더에 꽂힌다. 도착한 순간 체크가 찍히고 ‘정리 완료’ 간판에 불이 들어온다.
- **산나비풍 네온과 벚꽃** — 먼 배경에는 황혼 속 산업도시의 실루엣을, 전경에는 오래된 벚꽃나무와 낮은 가지를 둔다. 청록 네온은 간판이 켜지는 순간에 집중한다. 끝에서는 불빛이 잦아들고 다음 종이 모서리가 들리며 첫 장면으로 돌아간다.

## 두 가지 화면으로 내보내기

| 화면 | 구도 | 확인할 점 |
| --- | --- | --- |
| PC 와이드 | 왼쪽 벚꽃나무에서 에반과 미르를 지나 오른쪽 폴더와 간판까지 보인다. | 종이 한 장의 이동을 눈으로 따라갈 수 있는가? |
| 모바일 클로즈업 | 에반과 미르를 중앙에 크게 놓고 폴더와 간판은 에반 어깨 너머로 옮긴다. 마법 궤적도 짧게 다시 잡는다. | 가로 360px에서 미르의 시선과 ‘정리 완료’가 읽히는가? |

같은 캐릭터 프레임과 타이밍을 두 구도에 쓴다. 아래는 **향후 프로필 README에 넣을 예시**다. 내보낸 두 파일을 프로필 저장소의 `assets/`에 넣고 실제 GitHub 화면에서 폭을 바꿔 확인한다. 600px은 첫 시안의 전환 기준이다.

```html
<picture>
  <source media="(max-width: 600px)" srcset="./assets/banner-mobile.webp">
  <img src="./assets/banner-wide.webp" width="100%"
       alt="벚꽃 아래에서 에반과 미르가 마법으로 서류를 정리하자 네온 간판이 켜진다.">
</picture>
```

## 마우스와 터치

프로필 README에서는 자동 루프를 재생한다. 직접 조작하는 장면은 GitHub Pages로 만들고, 실제 페이지 주소가 생기면 배너 전체를 그 주소로 연결한다. README는 스크립트를 제거하고, Pages는 HTML·CSS·JavaScript를 실행할 수 있다. [GitHub의 README 처리 방식](https://github.com/github/markup#github-markup) · [GitHub Pages 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

- 마우스를 움직이면 미르의 눈이 먼저 따라가고 고개가 뒤따른다. 포인터가 장면을 벗어나면 기본 포즈로 돌아간다.
- 흩날리는 종이를 클릭하거나 터치하면 에반이 해당 종이를 폴더로 보내고 네온 간판이 켜진다. 모바일에서는 호버 없이 첫 탭으로 마법이 발동한다.
