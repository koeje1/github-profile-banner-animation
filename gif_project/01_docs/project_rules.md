# 프로젝트 운영 규칙

## 기준

- 유일한 최종 정답 이미지는 `../00_reference/master_reference.png`다.
- 캔버스는 1913 × 822 px, 좌표 원점은 좌상단 `(0, 0)`으로 고정한다.
- 원본의 구도, 픽셀 밀도, 팔레트, 조명, 분위기, 오브젝트 위치를 재해석하지 않는다.

## 승인 게이트

1. 한 번에 자산 하나만 제작한다.
2. 자산마다 원본 좌표 기준 합성 미리보기를 만든다.
3. 합성 미리보기 승인 전에는 다음 자산을 제작하지 않는다.
4. 승인된 버전만 `02_master/`의 조립 기준에 등록한다.
5. 불합격 버전은 다른 자산의 입력으로 사용하지 않는다.

## 금지

- 전체 하늘, 전체 전경, 전체 나무, 전체 지면을 움직이는 대형 레이어
- 실패한 `sky`, `sky_far`, `foreground`, `tree`, `ground`의 수정·승계
- `speech_text_sheet`, `star_twinkle` 계열의 재생성
- 원본 좌표 미리보기 없는 승인
- 흐릿한 보간, 안티앨리어싱 추가, 벡터풍 재해석
- 승인 전 파일의 대량 변형 또는 중복 생성

## 검수 기록

각 자산 검수 시 다음 항목을 기록한다.

- 자산명과 버전
- 원본 기준 바운딩 박스와 등록점
- 프레임 수와 루프 길이
- 사용 팔레트 또는 색상 차이
- 합성 미리보기 경로
- 판정: `candidate`, `review`, `approved`, `deprecated`
- 판정 이유와 다음 수정 범위

## 현재 단계

현재 단계의 허용 산출물은 폴더 구조, 기준 이미지 사본, 계획/규칙 문서뿐이다. 이미지 자산, 프레임 시퀀스, GIF는 만들지 않는다.
