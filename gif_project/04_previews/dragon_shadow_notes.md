# dragon_shadow 제작 기록

## 자산 규격

- 파일: `../03_assets/characters/shadows/dragon_shadow.png`
- 크기: 136 × 20 px
- 형식: 투명 RGBA PNG
- 유형: 정적 그림자 1개

## 색상

hero 그림자와 같은 남보라·남갈색 계열을 사용하되 작은 캐릭터에 맞게 불투명도를 조금 낮췄다.

- 외곽: `#1E1631`, alpha 50
- 중간: `#221730`, alpha 74
- 중심: `#27192E`, alpha 90

블러 없이 2px 단위의 계단형 타원 세 단계로 구성했다.

## 위치 기준

- 기존 dragon 기준 좌표: `(453, 416)`
- 최종 확정 오프셋: `x=-32`
- 최종 dragon 합성 좌표: `(421, 416)`
- dragon 발 접지선: 장면 `y=596`
- 그림자 합성 좌표: `(487, 583)`

그림자는 머리와 꼬리 전체 폭이 아니라 최종 위치에서의 몸통과 발 분포 `x≈505–604`를 중심으로 잡았다. hero 그림자보다 낮고 짧게 만들어 작은 체형과 네 발 접지에 맞췄다.

## 정적 사용 판단

현재 4프레임의 몸 중심과 공통 접지선이 안정적이므로 정적 그림자로 사용할 수 있다. 최종 GIF에서 네 발의 교대가 강조되어 그림자 폭이 고정된 느낌이 생길 때만 2프레임의 미세한 폭 변화 시트로 확장하는 것을 권장한다.
