# hero_walk 제자리 보행 정렬 기록

## 수정 범위

- 캐릭터의 얼굴, 몸, 다리, 망토, 지팡이와 보석 픽셀은 다시 그리지 않았다.
- 각 `300 × 280px` 프레임 안에서 캐릭터 전체의 수평 배치만 이동했다.
- 세로 좌표와 발 접지선 `y=252`는 변경하지 않았다.
- 원본 장면과 일치하는 F1 위치를 기준점으로 유지했다.

## 기존 문제

기존 시트의 얼굴 중심은 프레임 순서대로 대략 다음 위치였다.

| 프레임 | 기존 얼굴 중심 x |
|---|---:|
| F1 | 159.61 |
| F2 | 166.24 |
| F3 | 179.45 |
| F4 | 186.46 |

프레임이 진행될수록 캐릭터 전체가 오른쪽으로 전진한 뒤
`F4 → F1`에서 다시 왼쪽으로 돌아가, 제자리 걷기가 아니라 앞뒤로
움직이는 것처럼 보였다.

## 적용한 수평 보정

| 프레임 | 수평 이동 |
|---|---:|
| F1 | `0px` |
| F2 | `-7px` |
| F3 | `-20px` |
| F4 | `-27px` |

보정 후 얼굴 중심은 `159.61 / 159.24 / 159.45 / 159.77px`로 정렬되며,
최대 편차는 1픽셀 미만이다.

## 유지된 기준

- 시트 크기: `1200 × 280px`
- 프레임 크기: `300 × 280px`
- 프레임 수: 4
- 합성 원점: `(625, 344)`
- 발 접지선: 프레임 내부 `y=252`, 장면 기준 `y=596`
- 검수 GIF 속도: 프레임당 `130ms`
- F1의 원본 좌표와 실루엣
- 투명 PNG와 기존 픽셀 팔레트

## 검수 결과

- 머리와 몸이 프레임마다 앞으로 누적 이동하지 않는다.
- `F4 → F1`에서 발생하던 큰 수평 복귀가 제거됐다.
- 다리 교차와 망토 움직임은 유지되므로 제자리 걷기 동작으로 보인다.
- 모든 프레임의 발바닥 높이가 동일하다.
- 프레임 어느 쪽에서도 캐릭터 픽셀이 캔버스 경계에 잘리지 않는다.

## 연동 참고

hero 전체가 정렬되면서 F2~F4의 지팡이 보석 장면 좌표도 함께 왼쪽으로
이동했다. 기존 `magic_effect`는 이전 보석 좌표를 기준으로 제작되어 있으므로,
최종 통합 애니메이션 전에 magic 시작점의 프레임별 좌표만 별도로 맞춰야 한다.
이번 수정에서는 요청 범위를 지키기 위해 `magic_effect` 자산은 변경하지 않았다.

## 처리 방식

픽셀을 재생성하면 캐릭터 형태가 바뀔 위험이 있어 built-in ImageGen으로
재창작하지 않고, 승인된 기존 시트에 결정론적 정수 픽셀 이동만 적용했다.
수정 전 결과는 `../99_deprecated/hero_walk_forward_motion_20260730/`에 보관했다.
