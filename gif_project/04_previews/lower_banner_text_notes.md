# lower_banner_text 제작 기록

## 출력 규격

- 자산: `../03_assets/ui/lower_banner_text_sheet.png`
- 이미지 프레임 수: 정확히 6개
- 프레임 크기: `1284 × 92px`
- 전체 시트 크기: `7704 × 92px`
- 배경: 완전 투명
- 알파: `0/255`만 사용하는 이진 알파
- 포함 요소: 텍스트만
- 제외 요소: lower banner 본체, 배경, 커서, 그림자, 외곽선, 발광, 아이콘

## 프레임별 문구

| 프레임 | 문구 |
|---|---|
| F1 | `Always` |
| F2 | `Always learning.` |
| F3 | `Always learning. Always` |
| F4 | `Always learning. Always improving.` |
| F5 | `Always learning. Always improving. Always` |
| F6 | `Always learning. Always improving. Always automating.` |

## 위치와 정렬

- 모든 프레임의 고정 시작 좌표: lower banner 로컬 기준 `(159, 34)`
- 최종 문구 불투명 픽셀 경계: `(159, 34) ~ (1159, 67)`
- 전체 장면 합성 시 lower banner 원점: `(335, 673)`
- 전체 장면 기준 텍스트 시작점: `(494, 707)`
- 왼쪽 정렬 고정
- 프레임마다 전체 문장을 재정렬하지 않고 오른쪽으로 새 단어만 추가
- 이전 프레임에 이미 나온 모든 픽셀은 다음 프레임에서 위치와 RGB 값이 동일

## 글자 스타일과 색상

새 폰트를 추정해서 다시 그리지 않고 최종 정답 이미지의 하단 문구 픽셀을 직접 역분리했다.
따라서 글꼴 형태, 자간, 픽셀 밀도와 단어별 색상은 원본을 그대로 따른다.

- `Always`와 구두점: 밝은 백회색, 대표 중앙값 `#E7E5E6`
- `learning`: 보라/분홍, 대표 중앙값 `#B76AC2`
- `improving`: 청록/하늘색, 대표 중앙값 `#70A4C1`
- `automating`: 주황/살구색, 대표 중앙값 `#DA886E`

원본의 픽셀 내부 명암 단계는 유지하되 반투명 안티앨리어싱은 사용하지 않았다.
추출된 글자 픽셀은 모두 완전 불투명이고 나머지는 완전 투명이다.

## 한 줄 배치 검수

- 최종 문구 폭: `1001px`
- lower banner 내부에서 오른쪽 장식 시작 전까지 한 줄로 들어감
- 왼쪽 장식과 텍스트 사이 여백 유지
- 오른쪽 마침표와 오른쪽 장식 사이 여백 유지
- lower banner의 크기나 승인 자산은 변경하지 않음

## 권장 타이밍

- F1~F5: 각 `200ms` 권장 (`180~220ms` 조정 가능)
- F6: `1400ms` 권장 (`1200~1600ms` 조정 가능)
- 재생 정책: F1부터 F6까지 한 번 재생한 뒤 F6 유지
- 검수용 GIF에는 실제 이미지 프레임 6개만 저장
- 마지막 유지 시간은 F6 이미지를 복제하지 않고 GIF duration으로 기록
- 무한 반복을 전제로 하지 않음

## 자체 검수

- 실제 이미지 프레임 수 6개: 통과
- 지정 문구와 구두점: 통과
- 공통 시작점과 왼쪽 정렬: 통과
- 기존 글자 픽셀의 프레임 간 위치·RGB 불변: 통과
- 단어별 색 강조: 통과
- 한 줄 배치 및 장식 비침범: 통과
- 이진 알파와 투명 배경: 통과
- 승인 자산 무변경: 작업 전후 SHA-256 해시 일치

현재 결과는 최종 조립 단계로 넘길 수 있는 승인 후보 상태다.
