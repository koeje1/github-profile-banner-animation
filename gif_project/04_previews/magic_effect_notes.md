# magic_effect 제자리 hero 좌표 재정렬 기록

## 수정 목적

`hero_walk`가 제자리 보행으로 정렬되면서 F2~F4의 지팡이와 보석도
왼쪽으로 이동했다. 기존 magic 시작점은 이전 hero 좌표를 따르고 있어,
캐릭터나 이펙트를 다시 그리지 않고 프레임별 시작 좌표만 다시 맞췄다.

## 보석 및 magic 시작 좌표

장면 합성 원점은 기존과 동일한 `(850, 241)`이다.

| 프레임 | 이전 장면 보석 중심 | 새 장면 보석 중심 | 새 magic 내부 시작점 |
|---|---:|---:|---:|
| F1 | `(884,422)` | `(884,422)` | `(34,181)` |
| F2 | `(885,422)` | `(878,422)` | `(28,181)` |
| F3 | `(900,422)` | `(880,422)` | `(30,181)` |
| F4 | `(907,422)` | `(880,422)` | `(30,181)` |

새 좌표는 정렬된 `hero_walk_sheet.png`에서 보석의 청록색 픽셀 중심을
직접 다시 측정해 결정했다.

## 보정 방식

- F1은 기준 프레임이므로 변경하지 않았다.
- F2는 시작점을 `x=35 → 28`로 이동했다.
- F3는 시작점을 `x=50 → 30`으로 이동했다.
- F4는 시작점을 `x=57 → 30`으로 이동했다.
- 프레임 왼쪽부터 기존 시작점까지의 영역은 새 시작점 폭에 맞춰 압축했다.
- 시작점부터 오른쪽 끝까지의 리본 전체는 하나의 연속 스트립으로 확장했다.
- 모든 리샘플링은 최근접 픽셀 방식으로 처리했다.
- 장면 오른쪽의 리본 끝점과 paper_effect 주변 좌표는 고정했다.

## 유지된 요소

- `3400 × 360px` 시트와 프레임당 `850 × 360px` 규격
- 4프레임, 프레임당 140ms
- 리본 모양, 별 팔레트와 입자 구성
- 투명 PNG
- 레이어 순서:
  `background → shadows → hero/dragon → magic_effect → paper_effect`
- hero, dragon, paper, background 원본 파일

## 검수 결과

- 모든 프레임의 보석 중심 픽셀과 magic 중심광이 겹친다.
- F2~F4에서 시작광이 보석 오른쪽에 떨어져 보이던 좌표 차이가 제거됐다.
- 왼쪽 오라와 입자가 캔버스 경계에서 잘리지 않았다.
- 오른쪽 리본 끝이 프레임마다 이동하지 않는다.
- paper_effect는 기존처럼 magic_effect보다 위에 합성된다.

이번 작업은 built-in ImageGen이나 CLI 재생성을 사용하지 않고,
승인된 magic 시트에 결정론적 정수 좌표 재매핑만 적용했다.
수정 전 파일은
`../99_deprecated/magic_effect_pre_stationary_hero_20260730/`에 보관했다.
