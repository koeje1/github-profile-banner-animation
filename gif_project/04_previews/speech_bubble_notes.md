# speech_bubble 제작 기록

## 기준 자료

- 최종 장면 기준: `../00_reference/master_reference.png`
- 디자인 기준: `C:/Users/user/OneDrive/Desktop/speech_bubble_empty.png`
- 제공 자산의 본체, 외곽선, 내부 색상과 하단 보라색 보조 픽셀을 유지했다.
- built-in ImageGen 편집 후보도 비교했지만, 제공 자산을 직접 정규화한 결과가
  외곽선과 픽셀 밀도를 더 정확히 보존해 최종 기반으로 선택했다.

## 크기와 합성 좌표

- 최종 자산 크기: `366 × 109 px`
- 장면 합성 좌표: `(638, 225)`
- 원본 완성 이미지에서 확인되는 말풍선 외곽 크기와 위치를 기준으로 맞췄다.
- 확대·축소에는 최근접 픽셀 리샘플링만 사용했으며 블러와 일반
  안티앨리어싱을 적용하지 않았다.

## 꼬리 위치

- 제공 자산을 전체 크기로 축소한 뒤 꼬리 픽셀 덩어리만 `x=+9px` 이동했다.
- 최종 꼬리 중심은 장면 기준 약 `x=802px`로, 원본의 하단 중앙보다 약간
  왼쪽인 위치와 일치한다.
- 꼬리 끝은 hero 머리와 진행 방향 쪽을 자연스럽게 가리킨다.

## 원본 대비 차이

- 원본 완성 이미지의 말풍선에는 한국어 문장이 있지만 신규 자산은 완전히 비어 있다.
- 본체 비율, 둥근 모서리, 어두운 외곽선과 꼬리 실루엣은 제공 자산을 유지했다.
- 새로운 장식, 아이콘, 광택, 그림자 또는 반짝임을 추가하지 않았다.

## 합성 순서와 검수

- 합성 순서:
  `background → shadows → hero/dragon → magic_effect → paper_effect → speech_bubble`
- 내부는 텍스트 없이 충분한 여백을 유지한다.
- 투명 PNG이며 모서리 바깥에 크로마키 색상이나 불필요한 배경이 없다.
- hero 머리 위에 합성했을 때 원본과 같은 위치감과 크기감을 유지한다.

현재 결과는 텍스트 자산을 별도로 올릴 수 있는 빈 말풍선 기준 자산으로 사용 가능하다.
