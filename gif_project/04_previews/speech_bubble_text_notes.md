# speech_bubble_text 제작 기록

## 출력 규격

- 자산: `../03_assets/ui/speech_bubble_text_sheet.png`
- 프레임 수: 정확히 10개
- 프레임 크기: `366 × 109px`
- 시트 크기: `3660 × 109px`
- 투명 PNG
- 텍스트만 포함하며 말풍선 본체, 배경, 커서, 그림자와 이펙트는 포함하지 않는다.

## 프레임별 문구

| 프레임 | 문구 |
|---|---|
| F1 | `반` |
| F2 | `반복` |
| F3 | `반복은` |
| F4 | `반복은 내` |
| F5 | `반복은 내가` |
| F6 | `반복은 내가 처` |
| F7 | `반복은 내가 처리` |
| F8 | `반복은 내가 처리할` |
| F9 | `반복은 내가 처리할게` |
| F10 | `반복은 내가 처리할게.` |

## 텍스트 위치와 스타일

- 말풍선 내부 기준 렌더링 시작 좌표: `(38, 21)`
- 실제 최종 문장 불투명 경계: `(40, 27) ~ (331, 58)`
- 모든 프레임은 동일한 왼쪽 시작점과 기준선을 사용한다.
- 글꼴: `Hancom Gothic Bold`
- 글자 크기: `32px`
- 글자색: `#381F3D`
- 그레이스케일 안티앨리어싱을 제거한 이진 픽셀 마스크만 사용한다.
- 외곽선, 그림자, 블러와 발광은 사용하지 않는다.
- 각 프레임은 이전 프레임의 글자 픽셀을 그대로 유지하고 새 글자만 오른쪽에 추가한다.

## 타이핑 미리보기 타이밍

- F1~F9: 프레임당 `120ms`
- F10 완성 문장: `1400ms`
- 권장 완성 문장 유지 범위: `1200~1600ms`
- 검수용 GIF는 정확히 10개 이미지 프레임만 사용한다.
- F10 유지 시간을 만들기 위해 동일한 F10 이미지를 여러 번 복제하지 않고
  GIF frame duration 하나로 1400ms를 기록한다.

## 최종 조립 방식

4프레임, 6프레임, 10프레임의 최소공배수인 60장 또는 그 배수의 이미지
프레임을 미리 만들면 같은 화면이 대량 중복되고 파일 크기와 수정 비용이
불필요하게 증가한다. 각 레이어는 독립된 시간 상태로 계산한다.

- hero/dragon: `floor(time / 180ms) % 4`
- paper/magic: `floor(time / 140ms) % 4`
- speech text:
  `min(floor((time - typing_start) / 120ms), 9)`, F10 도달 후 고정
- lower banner text: 추후 6단계 상태를 독립 타이밍으로 계산

최종 GIF를 만들 때는 각 레이어 중 하나라도 상태가 바뀌는 시각만 합성
경계로 사용한다. 연속 합성 결과가 동일하면 이미지를 복제하지 않고
앞 프레임의 duration에 시간을 합산한다.

## 검수 결과

- 실제 텍스트 프레임 수는 10개다.
- 지정된 문구와 띄어쓰기, 마지막 마침표가 정확하다.
- 모든 프레임의 첫 글자 위치와 픽셀 형태가 동일하다.
- 최종 문장은 speech_bubble 안에 한 줄로 들어간다.
- hero, dragon, background, shadows, paper, magic와 speech_bubble은 수정하지 않았다.
- hero와 dragon의 속도 변경은 이미지 수정이 아니라 timing 문서에만 기록했다.

현재 결과는 최종 조립 단계로 넘겨도 되는 승인 후보 상태다.
