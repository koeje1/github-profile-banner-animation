# vine_cluster_A 제작 기록

## 선택한 군집

- 위치: 화면 왼쪽 큰 나무 몸통의 오른쪽 가장자리, 가운데 랜턴 아래쪽
- 내용: 나무에 붙어 오른쪽으로 뻗은 작은 청록색 잎 덩굴 한 군집
- 장면 bounding box: `(380, 334) ~ (441, 421)`
- 프레임 캔버스: `62 × 88px`
- 실제 F1 불투명 픽셀 경계: 로컬 `(6, 11) ~ (52, 76)`
- 실제 F1 불투명 픽셀 경계: 장면 `(386, 345) ~ (432, 410)`
- 합성 좌표: 프레임 좌상단을 장면 `(380, 334)`에 배치
- 고정점: 장면 `(397, 366)`, 로컬 `(17, 32)`

이 군집은 hero, dragon, 말풍선, 하단 배너와 겹치지 않고 큰 나무의 주 실루엣도 바꾸지 않는다.
오른쪽 끝잎과 아래 끝잎이 명확해 1픽셀 바람 변화를 제한적으로 적용하기 적합하여 선택했다.
기준은 `00_reference/master_reference.png`의 동일 좌표와 승인된
`02_master/background_master.png`의 깨끗한 배경 좌표다.

## 추출 및 배경 중복 처리

- `background_master`의 동일 구간을 확대 확인한 결과 원본 덩굴 군집이 이미 제거되어 있었다.
- 원본과 clean plate의 픽셀 차이를 제한된 군집 경계 안에서 비교해 원본 덩굴 픽셀만 역분리했다.
- 검은 마스크, 배경색 마스크, 크로마키, 나무 본체, 하늘, 먼 배경은 자산에 넣지 않았다.
- 실제 자산은 이진 알파 `0/255`의 투명 PNG다.
- F1은 원본 군집을 같은 좌표로 복원하므로 이중 윤곽이 없다.
- F2~F4는 원본 군집 픽셀을 계속 완전히 덮은 상태에서 끝픽셀만 1px 변형한다.
- 프레임 캔버스 사방에 투명 여백을 두어 불투명 픽셀이 경계에서 잘리지 않게 했다.

## 프레임별 변화

| 프레임 | 역할 | F1 대비 변경 범위 | 변경 픽셀 |
|---|---|---|---:|
| F1 | 원본에 가장 가까운 중립 자세 | 없음 | 0 |
| F2 | 오른쪽·아래 끝잎을 오른쪽으로 1px 누름 | 로컬 `(29,17)~(53,76)`, 장면 `(409,351)~(433,410)` | 546 |
| F3 | 중립 복귀 중 위쪽 작은 하이라이트만 아래로 1px 변화 | 로컬 `(39,18)~(49,22)`, 장면 `(419,352)~(429,356)` | 41 |
| F4 | 오른쪽·아래 끝잎을 반대 방향인 왼쪽으로 1px 누름 | 로컬 `(27,17)~(51,76)`, 장면 `(407,351)~(431,410)` | 546 |

변경 픽셀 수는 이동한 잎 내부의 색상 재배치와 외곽 1픽셀을 모두 센 값이다.
실제 공간 이동량은 1px이며 군집 전체의 좌표 이동은 없다.

## 고정점과 형태 안정성

- 고정점 주변 `9 × 9px`은 네 프레임에서 RGBA가 완전히 동일하다.
- 줄기 시작점, 왼쪽 작은 잎, 나무 접점은 고정했다.
- 움직임 선택 영역은 직사각형이 아니라 실제 잎 모양의 제한된 폴리곤이다.
- 줄기 옆에 투명 직선 틈이나 칼로 자른 경계가 생기지 않도록 원본 불투명 군집을 유지한 채 끝픽셀만 변형했다.
- 줄기 굵기, 잎 크기, 팔레트와 픽셀 밀도는 원본을 유지한다.

## 권장 재생 속도

- 프레임 수: 정확히 4개
- 권장 duration: 프레임당 `320ms`
- 허용 범위: 프레임당 `280~360ms`
- 전체 루프: 약 `1280ms`
- 재생 정책: 느린 반복 루프
- 다른 식생 자산과 완전히 같은 위상을 사용하지 말 것
