# 주 작업자 재검수 기록

2026-11-24. `all-frames-00.jpg`부터 `05.jpg`의 000–149번 캐릭터 프레임 전체, `scenes-0.jpg`와 `scenes-1.jpg`의 전체 장면 32개를 직접 확인했다. 후반 150프레임과 나머지 16개 전체 장면은 별도 검수자가 확인했으며 범위는 `visual-audit.md`에 있다.

원래 비율에서 앞·뒷다리의 연결, 발 교차, 몸통 윤곽, 코트와 팔 접합을 확인했다. 이 범위에서 분리된 조각이나 몸통 전체의 중복 윤곽은 관찰하지 못했다. 미르는 이전보다 지지점이 분명하지만 관절 표현이 여전히 단순하고, 에반의 상체 변화는 작다.

기계 검증 중 새로 발견한 문제는 건물 하단의 미세한 흔들림이었다. 풀 변형을 처리한 격자점이 건물에 걸친 셀로 영향을 전달했다. RGBA 차이의 알파값이 0인 경우 경계 판정으로 RGB 변화를 놓칠 수 있어, 비교를 RGB로 바꾼 검증에서 드러났다. 건물을 덮는 격자점을 고정했으며 검사 위치를 옮기지 않고 같은 건물 패치를 재검증한다. 이 수정은 캐릭터 영역에 영향을 주지 않는다.

인앱 브라우저 새 탭에서 로컬 재생 페이지를 열려고 했으나 연결 시간이 초과됐다. 기존 테스트 브랜치의 MP4 직접 접근도 브라우저에서 차단됐다. 화면 재생 검수를 통과했다고 기록하지 않는다. 디코딩 검사와 프레임 관찰은 체감 자연스러움의 완전한 검증을 대신하지 못한다.

건물 고정 후 같은 RGB 검사 위치가 300프레임 전체에서 일치했다. 최종 poster와 scenes-2를 다시 확인했고 새로 생긴 경계선은 보이지 않았다. 최종 MP4에서 0·9·17·26·149·299번 프레임을 직접 디코딩하여 동일 비율 2배 확대 시트로 확인했다(`mp4-decoded-review.jpg`). 이 샘플에서도 분리된 발이나 중복 몸통은 관찰하지 못했다.
