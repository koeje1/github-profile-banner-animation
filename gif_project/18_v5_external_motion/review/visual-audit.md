# 원본 도트 합성 독립 육안 검수

검수 날짜: 2026-11-24. 최종 출력은 30ms 간격의 672프레임, 20.16초 반복이다. 확인 자료: `exports/poster.png`, 갱신된 `motion-native-contact.png`와 `travel-contact.jpg`, `entry-exit-review.jpg`, `wind-extremes.jpg`, 원본 스프라이트의 `sprite_trial/evan-feet-proof.png` 및 `mir-stage-comparison.png`. 동작 비교 시트의 60ms 표시는 비교용 표본 간격이며 최종 파일의 프레임 간격은 30ms다.

이 독립 검수는 실제 이미지를 읽은 정지 프레임·연속 시트 검수다. 파일 디코딩 성공을 자연스러운 동작의 증거로 취급하지 않았으며, 전체 영상의 연속 재생을 봤다고 주장하지 않는다. 이 검수 이후 주 작업자가 GitHub GIF 뷰어의 서로 다른 세 재생 시점에서 이동·포즈 변화·재진입을 확인했다. 후속 브라우저 관찰 범위는 `exports/validation.json`에 구분해 기록했다.

## 확인한 개선

- 지면이 원래 그림의 잔디·흙·돌 구조를 유지한다. 검수 이미지에서 이전의 반복 바닥 띠, 수평 컨베이어 이음새, 바닥 전체의 늘어짐이 보이지 않는다.
- 에반은 머리·몸·팔·다리·지팡이가 한 장의 원본 포즈로 함께 바뀐다. 시트에서 팔과 다리의 접합 분리, 관절이 늘어지는 현상, 몸통 중복 외곽선은 보이지 않는다.
- 미르의 날개가 펴지고 접히는 6개 포즈와 꼬리의 곡선 변화가 일관된 원작 비행 동작으로 읽힌다. 발을 땅에 억지로 붙인 사족보행이 아니라 다리를 접은 채 낮게 따라가는 비행이다. 발 끝이 지면보다 15~18px 위인 것은 원본 origin에 따른 높이다.
- 에반의 지지발 밑창은 모든 원본 포즈에서 동일한 합성 기준선에 닿는다. 실제 이동 샘플에서도 발이 길 위에 놓인다. 미르와 에반 사이가 유지되며 서로 겹치지 않는다.
- 화면 양끝의 잘림은 밖으로 걸어 나가고 들어오는 장면 경계에서 발생한다. 화면 중앙에 있는 두 캐릭터의 머리, 날개, 꼬리, 지팡이가 임의의 크롭 사각형에 잘린 증거는 없다.
- 나무 비교 이미지에서 상단 가지와 꽃군집의 위치 변화가 확인된다. 트렁크·집·지면은 화면에서 안정적으로 유지되며, 비교한 극점 이미지에서 명확한 이중 외곽선이나 사각형 합성 이음새는 보이지 않는다. 바람의 체감 강도와 리듬은 연속 재생 판단이 필요하다.
- 최종 수정에서는 바람 변형을 나무 외곽의 국소 영역으로 제한해 하늘 변형을 제거했다. 전체 프레임의 구름 영역 `(706,139)-(787,164)` RGB 동일성 검증 결과가 제작 담당자로부터 전달되었다. 이는 정지 배경 보존에 대한 수치 검증이며, 연속 재생 육안 검수와는 별도로 구분한다.

## 남은 구체적인 문제와 판단

1. **에반 지팡이 끝이 포즈 3에서 땅을 스치는 원본 동작을 유지했다.** `motion-native-contact.png`의 540/600/660ms에서 기울어진 원형 장식의 하단 가시가 발 기준선보다 약 6px 낮게 내려간다. 이는 부츠 정렬 오류가 아니라 원본 게임 무기 포즈다. 잔디·상단 흙에 조금 박힌 것처럼 보이지만, 원작의 포즈와 정상적인 발 접지를 보존하는 선택으로 유지했다. 캐릭터 전체를 6px 올리면 정상인 지지발이 떠버린다.
2. **짧은 빈 풍경 구간은 의도한 연출로 유지했다.** 9~11초 전후에는 두 캐릭터가 화면 밖에 있고, 돌아올 때 에반이 먼저 들어온다. 이동 오류나 순간이동이 화면 안에서 드러나는 것이 아니라, 두 캐릭터가 길을 통과하고 다시 들어오기 사이에 풍경을 보여주는 여백이다.
3. **수평 이동 샘플은 30ms로 개선했으나 연속 재생 육안 품질은 아직 확정하지 않았다.** 최종 출력은 30ms마다 1~2px씩 이동하며, 에반 180ms·미르 120ms의 원본 포즈 시간은 그대로 보존한다. 앞선 60ms/약 3.3px 이동보다 위치 단계가 작아졌다. 정지 시트는 골격·접합·등록 문제를 찾는 데 유효하지만 이 이동이 실제 화면에서 충분히 부드러운지 판정할 수 없다. 현재 실제 화면 연속 재생을 직접 확인했다는 주장은 하지 않으며, 정상 속도 반복 재생에서 수평 이동과 GIF 색 변화에 대한 최종 육안 판단이 남는다.

선택한 2211 미르는 네 성장 단계 중 어린 용의 실루엣과 가장 가깝고, 성룡의 크고 높은 날개 및 후광이 없다. 실제 메이플 도트로 변경한다는 사용자의 선택에 맞는 조합이다. 삽화의 부드러운 배경과 원본 도트의 진한 외곽선 차이는 남지만, 현재 시트에서 형태 손상보다 먼저 보이는 문제는 아니다.
