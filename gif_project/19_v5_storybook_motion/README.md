# 삽화풍 배너 V19

따뜻한 판타지 삽화의 분위기를 유지하는 반복 배너다. 실제 게임 캐릭터를 사용했던 V18에서 돌아와, 승인 삽화를 참조해 생성한 소년과 어린 보라색 용의 전체 포즈로 구성했다.

## 이번 수정

- 에반의 후반 네 포즈를 다시 생성하고 다리 겹침과 들린 앞발을 수정했다. 머리 기준점과 같은 배율로 정렬해 포즈 전환 시 크기 변화를 줄였다.
- 지지발의 위치 변화에 맞춰 포즈 시간을 `180,210,150,180,180,180,240,120ms`로 조정했다. 1회 보행 주기 1.44초, 이동 속도 45.5px/s다.
- 미르는 날개 포즈를 `0,1,2,3,4,3,2,1`로 연결해 기존 4→5 전환을 제거했다. 0.96초 날갯짓과 1px 상하 이동을 사용한다. 지면과 날개 사이에 여유를 뒀다.
- 땅·집·나무줄기는 고정하고 가지와 꽃송이에 국소적으로 바람을 적용했다. 바람 주기는 5.76초다.
- 둘이 화면 밖으로 완전히 나간 뒤 반대편으로 돌아오게 했다. 캐릭터·바람·꽃잎·편지의 위상이 23.04초 경계에서 맞는다.

출력은 800×348, 768프레임, 30ms 간격이다. GIF는 하나의 255색 팔레트를 사용하고 MP4는 원래 색을 더 많이 유지한다. 소년과 용은 완성 포즈를 교체하며 관절 조각 변형·모핑·프레임 중첩을 사용하지 않는다.

## 검수 범위와 남는 한계

`export_loop.py`는 지면·집·줄기 고정, 보이는 중 순간이동하지 않는지, 반복 경계, GIF 전체 디코딩 결과, MP4 및 3회 반복 디코딩을 검사한다. 파일 검사를 움직임의 자연스러움과 동일하게 취급하지 않는다.

포즈를 유지하는 동안 발은 몸과 함께 조금 이동한다. 포즈 교체 순간의 접점 오차는 줄였지만 연속적인 접지까지 완전히 해결한 것은 아니다. 새 4번 포즈의 가까운/먼 다리 구분은 여전히 모호하고, 미르 2↔3 날개 각도 차이도 남는다. 이번 결과는 삽화풍과 반복 동작을 복구한 수정안이며 수작업으로 그린 다수의 중간 포즈와 같은 부드러움을 주장하지 않는다.

## 생성과 재현

이미지는 Codex 내장 `image_gen`으로 생성했다. [입력·정확한 프롬프트](PROMPTS.md)를 보존했다. 별도 유료 API나 CLI를 사용하지 않았고, 게임 스프라이트를 외형 참조에 넣지 않았다.

원본은 `assets/evan-walk-sheet.png`, `assets/evan-halfstep-v2.png`, `assets/mir-flight-sheet.png`다. 생성 알파는 그대로 유지한다. `prepare_evan.py`, `prepare_evan_v2.py`, `assets/mir/prepare.py`가 셀을 추출하고 정렬한다. `scenery.py`는 캐릭터 자산을 불러오지 않는 배경 전용 모듈이다.

```sh
python export_loop.py
```

기존 `test-banner-v5-single-contour` 브랜치에서 검토한다. 메인 배너 교체는 이 폴더 수정에 포함하지 않는다.
