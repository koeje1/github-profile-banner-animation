# V20 — 제자리 보행과 흐르는 풍경

에반과 미르의 화면 속 위치를 고정하고, 길·나무·집을 포함한 풍경 전체가 왼쪽으로 흐르게 바꿨습니다. 스태프는 손을 허리까지 내려 대각선으로 들고, 손목·팔꿈치·스태프가 함께 움직이는 포즈로 새로 그렸습니다.

- 에반: 완성된 전신 그림 16장, 각 80ms. 이전 8장보다 포즈 간격을 줄였습니다.
- 미르: 완성된 전신 그림 16장, 각 80ms. 날개의 중간 각도를 늘리고 앞발을 편히 내렸습니다.
- 화면: 800×348, 25fps, 23.04초. 배경 한 바퀴에 두 캐릭터의 1.28초 동작이 18번 들어갑니다.
- 배경: 1044px 풍경이 초당 45.3125px 이동합니다. 에반의 추정 평균 발 후퇴 속도는 45.65px/s입니다.
- 나무: 풍경 안의 잎·가지 영역에만 바람을 적용합니다. 길·뿌리·집은 같은 형태로 이동합니다.

## 그림 생성과 재현

모든 새 그림은 내장 `image_gen`으로 생성했습니다. 유료 CLI/API나 원본 게임 스프라이트는 사용하지 않았습니다. 그림체 기준은 이전 V17 삽화입니다.

- 에반 원본: `assets/evan-walk-16.png`; [프롬프트](EVAN_PROMPT.md)
- 미르 원본: `assets/mir/source-sheet-relaxed.png`; [최종 프롬프트](assets/mir/prompt-relaxed.txt)
- 배경 원본과 채택본: `assets/panorama-source-v1.png`, `assets/panorama.png`; [프롬프트 기록](assets/background-prompts.md)
- `python prepare_evan.py`
- `python assets/mir/prepare.py`
- `python export.py`

캐릭터는 전신 단위로 잘라 같은 배율로 축소하고 기준점을 정렬합니다. 팔다리 조각 회전, 관절 모핑, 알파 경계 지우기는 사용하지 않았습니다. GIF는 92색에 스태프의 청록 계열 4색을 예약한 공유 팔레트를 씁니다. 작은 크리스털이 배경 색 통계에 묻혀 크림색으로 바뀌던 문제를 방지합니다. MP4는 전체 색상의 H.264 영상입니다.

최종 GIF는 89.31MB, MP4는 5.64MB입니다. 해상도와 프레임 수를 유지하고 GIF 색상 수를 줄였습니다.

## 검수 범위

화면 속 위치 고정, 배경 전체의 이동, 주기 일치, 마지막→첫 프레임, GIF 전 프레임의 디코드 일치와 MP4 3회 반복 디코드를 확인합니다. 실제 그림에서는 낮아진 스태프와 늘어난 날개 중간 포즈, 지면과의 간격을 비교했습니다.

최종 출력에서 GIF 576프레임 디코드가 원본 팔레트 프레임과 모두 일치했고, MP4는 3회 반복 1728프레임을 오류 없이 디코드했습니다. Windows Media Player에서도 반복 재생을 열어 화면 속 캐릭터 위치와 지나가는 풍경을 표본 화면으로 확인했습니다. 연속 동작 전체를 눈으로 추적했다는 뜻은 아닙니다. 작은 청록 크리스털도 GIF에서 색이 유지되는지 별도로 비교했습니다.

아직 발 접촉 속도가 포즈마다 고르지 않아 미세한 미끄러짐이 남습니다. 에반의 두 반주기에서 다리 실루엣이 비슷하고, 미르의 마지막→첫 포즈에 작은 꼬리 형태 변화가 있습니다. 배경 접합의 하늘에도 약한 밝기 차이가 남습니다. 파일 검증 통과를 자연스러운 보행의 증명으로 간주하지 않습니다.
