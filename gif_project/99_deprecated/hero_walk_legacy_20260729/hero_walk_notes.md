# hero_walk 검수 노트

## 출력

- 자산: `../03_assets/characters/hero_walk_sheet.png`
- 정적 합성 미리보기: `hero_walk_composite_preview.png`
- 원본 기준: `../00_reference/master_reference.png`
- 합성 배경: `../02_master/background_master.png`

## 자산 형식

- 4프레임 가로 스프라이트 시트
- 전체 크기: 1120 × 272 px
- 프레임 크기: 280 × 272 px
- 프레임 순서: 오른발 접지 → 통과/상승 → 반대 접지 → 통과/상승
- 재생 권장 순서: `0 → 1 → 2 → 3`
- 권장 프레임 유지 시간: 프레임당 110–140 ms
- 알파: 완전 투명 또는 완전 불투명만 사용하는 이진 알파

## 원본 좌표 합성

- 정적 검수 프레임: 프레임 0
- 셀 좌상단 배치 좌표: `(638, 348)`
- 접지선: 약 `y=596`
- 프레임 0 내부 불투명 바운딩 박스: `(48, 19)–(271, 247)`
- 실제 장면 점유 범위: 약 `(686, 367)–(909, 595)`

`hero_walk_composite_preview.png`는 3826 × 822 px이다. 왼쪽은 완성 원본, 오른쪽은 승인된 `background_master` 위에 프레임 0만 원본 좌표로 합성한 장면이다.

## 재사용한 기존 자산

- `background_master.png`: 정적 합성 기반으로 그대로 재사용
- `master_reference.png`: 영웅의 외형, 팔레트, 크기, 위치와 접지선 검수 기준으로 사용

다른 캐릭터, 효과 또는 UI 자산은 사용하지 않았다.

## 신규 제작/복원

- 원본 영웅을 기준으로 동일한 외형의 최소 4프레임 보행 주기를 신규 제작
- 남색 후드 망토, 갈색/금색 테두리, 갈색 벨트와 부츠, 짙은 갈색 머리와 지팡이 팔레트 유지
- 프레임별 다리 교차, 상하 움직임, 망토 끝의 미세한 변화 추가
- 원본 지팡이의 청회색 다면 보석 본체와 갈색 포크형 연결 구조를 네 프레임에 포함
- 단색 크로마 배경을 제거하고 픽셀아트용 이진 알파로 정리
- 원본 캐릭터 높이에 맞춰 최근접 보간으로 축소 및 공통 접지선 정렬

## 지팡이 보석 수정

- 수정 범위: 각 프레임의 지팡이 끝 주변 작은 패치만 교체
- 유지 범위: 얼굴, 머리, 손, 자세, 망토, 다리, 접지선과 프레임 간격
- 보석 구성: 짙은 청회색 외곽선, 푸른 그림자 면, 옅은 얼음색 주면, 작은 흰색 하이라이트
- `hero_walk` 포함: 비발광 보석 본체와 물리적 연결 구조
- 후속 effect layer 포함: 발광, 블룸, 반짝임, 회전 마법 궤적과 입자
- 보석 국소 수정 외 영역에서 변경된 픽셀: 0

## 합성 검수 포인트

1. 발이 잔디 위에서 미끄러지지 않고 `y≈596` 접지선을 유지하는지 확인한다.
2. 프레임 전환 때 얼굴, 머리 크기, 망토 외곽과 벨트 위치가 흔들려 보이지 않는지 확인한다.
3. 물리 보석은 현재 시트에 포함된다. 이후 `wand_magic_core`는 보석 위의 발광·반짝임·마법 궤적만 등록해야 한다.
4. 현재 정적 합성은 아직 승인되지 않은 dragon, paper effect, 말풍선, 하단 배너를 포함하지 않는다. 비교 시 영웅의 크기·좌표·팔레트만 우선 본다.
5. 원본보다 망토 끝의 후방 폭이 프레임별로 달라지므로 dragon과 합성할 때 겹침 순서를 확인한다.

## 현재 판정

원본 좌표와 접지선에 맞는 4프레임 후보 자산으로 사용할 수 있다. 캐릭터 실루엣과 팔레트는 장면에 자연스럽게 들어가며, 지팡이의 물리 보석까지 포함한다. 가장자리에는 녹색 키나 반투명 선이 남지 않도록 정리했다.
