# magic_effect 제작 및 검수 기록

## 기준과 기존 파일 처리

- 최종 기준 이미지: `../00_reference/master_reference.png`
- 승인 배경: `../02_master/background_master.png`
- 승인 캐릭터: `../03_assets/characters/hero_walk_sheet.png`, `../03_assets/characters/dragon_walk_sheet.png`
- 승인 그림자: `../03_assets/characters/shadows/hero_shadow.png`, `../03_assets/characters/shadows/dragon_shadow.png`
- 승인 paper layer: `../03_assets/effects/paper_effect_sheet.png`
- 활성 프로젝트와 deprecated 폴더에 기존 `magic_effect` 결과가 없어 이동 또는 폐기 작업은 발생하지 않았다.
- 원본 완성 이미지에서 마법 요소만 새로 추출했으며 기존 자산을 수정하거나 마법의 입력으로 재사용하지 않았다.

## 생성 방식과 프롬프트

built-in ImageGen의 정밀 오브젝트 편집 방식으로 원본에서 다음 요소만 보존하도록 지시했다.

- 지팡이 보석 중심에서 시작되는 청백색 발광
- 보석 외곽의 작은 오라와 회전감
- 중앙~오른쪽으로 이어지는 두 줄의 S자형 리본 흐름
- 경로 주변의 청백색·시안 입자와 별 반짝임
- 오른쪽 영역의 소수 금빛·복숭아빛 반짝임

hero, 지팡이와 보석 본체, dragon, 종이·문서·폴더·체크·봉투, 배경, UI와 신규 마법 문양은 제외하도록 지정했다. 생성 단계의 배경은 투명화용 단색 `#ff00ff`로 제한했다.

후속 수정에서는 기존 F1을 편집 대상으로 ImageGen에 전달해 보석 모양 음각 제거, 오른쪽이 열린 끊어진 오라, 별 밀도 축소와 색·크기 다양화를 검토했다. 생성 참고본은 리본 경로와 두께를 크게 바꿔 직접 사용하지 않았고, 현재 승인 리본 경로를 유지한 채 해당 수정 규칙만 결정적으로 적용했다.

## 출력 규격과 합성 기준

- 자산: `../03_assets/effects/magic_effect_sheet.png`
- 전체 시트: 3400 × 360 px
- 프레임: 4개
- 프레임 캔버스: 각 850 × 360 px
- 프레임 순서: `F1 → F2 → F3 → F4 → F1`
- 검수 GIF: 프레임당 140 ms, 무한 반복
- 장면 합성 원점: `(850, 241)`
- dragon 합성 좌표: 최종 `x=-32px`이 반영된 `(421, 416)`
- 알파 단계: `0`, `48`, `80`, `128`, `192`, `255`

크로마 제거 후 효과 묶음을 840 × 250 px로 최근접 이웃 정규화했다. 일반 안티앨리어싱이나 흐림 보간은 사용하지 않았다.

## 프레임별 hero 보석 중심 좌표

hero 시트의 프레임별 보석 중심을 장면 좌표에 반올림해 사용했다.

| 프레임 | hero 내부 기준 | 장면 좌표 | magic 프레임 내부 좌표 |
|---|---:|---:|---:|
| F1 | 약 `(258.6, 78.4)` | `(884, 422)` | `(34, 181)` |
| F2 | 약 `(259.6, 78.2)` | `(885, 422)` | `(35, 181)` |
| F3 | 약 `(274.7, 78.2)` | `(900, 422)` | `(50, 181)` |
| F4 | 약 `(281.6, 77.6)` | `(907, 422)` | `(57, 181)` |

각 프레임에서 오라와 중심 십자 발광을 해당 좌표에 직접 등록했다. 보석 본체는 포함하지 않는다.

## 보석 중심 발광과 시작 오라

- 기존 효과에 파여 있던 보석 모양의 음각과 큰 원형 버블을 제거했다.
- 보석 중심에는 중심 1px과 상하좌우 2px 범위의 작은 가산 청백색 발광만 겹쳤다.
- 오라는 완전한 원이 아니라 오른쪽이 열린 2–3개의 끊어진 픽셀 호로 구성했다.
- 프레임별 외곽 호의 가로 반경은 `10 → 11 → 10 → 9px`, 세로 반경은 `8 → 9 → 8 → 7px`이다.
- 오라 알파는 `80–128`, 보석 중심 발광은 `192–255` 범위를 사용한다.
- effect 자체에 보석 실루엣이나 보석 모양의 투명 구멍이 없으므로 아래 hero 시트의 실제 보석 형태가 그대로 유지된다.

## 중앙~오른쪽 리본 경로

- 서로 가까이 붙은 두 개의 청백색 리본이 완만한 S자형 경로를 공유한다.
- F1 기준 시작점은 프레임 내부 `(34,181)`이다.
- F2–F4에서는 hero 보석의 이동량 `+1`, `+16`, `+23px`을 시작부에 반영한다.
- 시작 약 80px 구간은 보석을 완전히 따라가고, 이후 280px 구간에서 수평 변위를 점진적으로 0으로 감쇠한다.
- 중앙 이후와 오른쪽 종착점은 화면상 고정되어 전체 흐름이 좌우로 흔들리지 않는다.
- 경로 길이와 종착점은 네 프레임에서 동일하다.

## 애니메이션 변화

| 프레임 | 중심 발광 | 시작 오라 | 리본·잔광 | 입자·별 |
|---|---|---|---|---|
| F1 | 기준 밝기 | 열린 호 `10×8px` | 기준 대비 약 94% | 기준 위치 |
| F2 | 가장 밝음 | 열린 호 `11×9px` | 최대 밝기·알파 | 위상별 `1px` 이동 |
| F3 | 중간 밝기 | 열린 호 `10×8px` | 완만한 감쇠 | 일부 코어 `1–2px` 진행 |
| F4 | 낮은 밝기 | 열린 호 `9×7px` | 기준 대비 약 90% | 복귀 방향 이동 |

기존 작은 별·입자 연결 요소의 약 25%를 줄여 106개의 변형 기준점을 유지했다. 약 30%는 1px 점, 50%는 3px 십자, 나머지는 5px 중심의 강조 별과 소수 7px 별로 재구성했다. 흰색·옅은 시안·하늘색·민트색을 교차하고 약 23개당 1개 비율로 금빛·복숭아빛 포인트를 사용했다.

별과 점형 입자는 네 위상 그룹으로 나눴다. 각 그룹은 서로 다른 프레임에서 `55–100%` 밝기 리듬과 최대 2px 이동을 사용하므로 모든 반짝임이 동시에 켜지거나 꺼지지 않는다. 프레임 사이에서 기준점 개수는 변하지 않는다.

## 투명도와 색상

- 핵심 리본과 보석 중심: alpha `255`
- 밝은 리본 가장자리와 별 중심: alpha `192–255`
- 시작 오라와 흐름 주변부: alpha `80–192`
- 넓은 잔광과 작은 점: alpha `48–128`
- 주 팔레트: 밝은 흰색, 옅은 시안, 하늘색, 청백색
- 포인트: 소수의 금빛·복숭아빛 별

회색 또는 탁한 파랑으로 죽지 않도록 낮은 알파에서도 RGB는 맑은 시안 계열을 유지했다. 블러나 에어브러시 대신 제한된 알파 단계와 계단형 픽셀 곡선을 사용했다.

## 원본 대비 차이와 현재 판단

보석 시작점, 2중 리본의 방향, 중앙 파동과 오른쪽 반짝임 영역은 원본과 유사하다. 이전 결과의 보석 모양 구멍과 큰 원형 오라가 사라져 프레임별 보석 실루엣이 어긋나는 문제가 없어졌다. 별은 원본보다 약간 정돈된 분포이지만 단색 반복 대신 크기와 색의 층이 생겼다. paper layer를 위에 합성하면 원본처럼 문서 흐름을 뒤에서 받쳐주는 구조가 분명해진다.

하나의 시트 안에서 보석 발광·오라·리본·입자·반짝임을 함께 제어할 수 있어 front/back 분리는 필요하지 않다. 요청한 20개 검수 기준을 충족하는 승인 후보이며 다음 자산은 자동 생성하지 않는다.
