# magic_effect 신규 재생성 기록

## 기존 결과 처리

- 이전 `magic_effect` 시트와 미리보기 7개는 재생성 전에
  `../99_deprecated/magic_effect_broken_20260730/`로 이동했다.
- 이전 시트, 마스크, 크롭, 픽셀 데이터는 새 결과의 입력으로 사용하지 않았다.
- 새 결과는 `master_reference.png`의 위치·팔레트와 승인된 hero/paper 합성 좌표를
  기준으로 built-in ImageGen에서 처음부터 생성했다.

## 출력 규격

- 실제 자산: `../03_assets/effects/magic_effect_sheet.png`
- 4프레임, 프레임당 `850 × 360 px`, 전체 `3400 × 360 px`
- 투명 PNG, 프레임당 140 ms 검수 루프
- 장면 합성 원점: `(850, 241)`
- 레이어 순서:
  `background → shadows → hero/dragon → magic_effect → paper_effect`

## 보석 시작부

- 보석 본체나 보석 모양의 투명 구멍을 만들지 않았다.
- 시작부는 실제 hero 보석 위에 겹치는 작은 십자형 중심광과 오른쪽으로 열린
  비대칭 호로 구성했다.
- 프레임별 장면 기준 보석 중심은
  `F1 (884,422)`, `F2 (885,422)`, `F3 (900,422)`, `F4 (907,422)`이다.
- 프레임 내부 기준은 각각
  `F1 (34,181)`, `F2 (35,181)`, `F3 (50,181)`, `F4 (57,181)`이다.
- 시작점만 hero 지팡이를 따라가고, 리본의 먼 끝은 같은 좌표에 고정되도록
  리본 전체를 하나의 연속 스트립으로 최근접 픽셀 리샘플링했다.

## 리본과 별

- 두 갈래 청록/흰색 S자 리본과 주변 입자를 하나의 `magic_effect` 자산에 포함했다.
- 별은 흰색, 옅은 청록, 하늘색, 민트색을 주조로 하고 금색/복숭아색을 소량 섞었다.
- 점형, 중형 십자형, 큰 4방향 별의 세 크기군을 유지했다.
- 프레임 사이에는 형태를 다시 그리지 않고 제한 팔레트의 일부만 교대해
  작은 밝기 맥동을 만들었다.

## 포함 / 제외

- 포함: 보석 중심광, 열린 오라, 두 갈래 마법 리본, 경로 입자, 다색 별 반짝임.
- 제외: 보석 본체, 지팡이, hero/dragon, 종이·폴더·체크 UI, 배경, 말풍선,
  하단 배너.

## 자체 검수

- 새 소스의 리본 시작부와 끝부분이 잘리지 않았다.
- 닫힌 보석형 구멍, 음영 마스크, 어두운 컷아웃이 없다.
- 각 프레임의 시작광 중심이 승인된 hero 보석 중심과 일치한다.
- 리본은 frame 경계 안에 있고, F4 → F1 연결에서도 끝점이 튀지 않는다.
- 합성 순서상 paper_effect가 magic_effect보다 위에 있다.
- 출력 시트에는 녹색/자홍색 크로마 배경이 남아 있지 않다.

현재 결과는 이전 결과의 누적 수정본이 아니라 완전히 새로 생성한 검수 후보이며,
`magic_and_paper_composite_preview.png`를 승인 기준으로 사용한다.
