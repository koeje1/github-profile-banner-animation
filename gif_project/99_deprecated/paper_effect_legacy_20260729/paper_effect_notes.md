# paper_effect 제작 및 검수 기록

## 기준과 기존 파일 처리

- 최종 기준 이미지: `../00_reference/master_reference.png`
- 승인 배경: `../02_master/background_master.png`
- 승인 캐릭터: `../03_assets/characters/hero_walk_sheet.png`, `../03_assets/characters/dragon_walk_sheet.png`
- 승인 그림자: `../03_assets/characters/shadows/hero_shadow.png`, `../03_assets/characters/shadows/dragon_shadow.png`
- 활성 프로젝트에 기존 `paper_effect` 결과가 없어 deprecated 이동은 발생하지 않았다.
- 원본 중앙~우측 영역만 새 참조 이미지로 사용하여 built-in ImageGen으로 기본 효과 레이어를 한 번 생성했다.
- 프레임별 이미지를 따로 생성하지 않고 동일 기본 레이어를 결정적으로 변형하여 오브젝트 개수를 고정했다.

## 출력 규격

- 자산: `../03_assets/effects/paper_effect_sheet.png`
- 전체 시트: 3400 × 360 px
- 프레임: 4개
- 프레임 캔버스: 각 850 × 360 px
- 검수 GIF: 프레임당 140 ms, 무한 반복
- 장면 합성 원점: `(850, 241)`
- dragon 합성 원점: 최종 `-32px`이 적용된 `(421, 416)`

## 포함 오브젝트

- 지팡이 보석 앞에서 시작되는 원형 소용돌이
- 오른쪽으로 이어지는 두 줄의 청백색 리본형 마법 궤적
- 중앙 흐름과 종이 더미 주변의 문서 15장 구성
- 지면에 놓이는 종이 더미 1개
- 주황색 폴더 2개
- 큰 체크 문서 카드 2개
- 흰색 봉투 1개
- 작은 체크 메모 카드 1개
- 보라색 문서 줄이 있는 클립보드 1개
- 청색·흰색·복숭아색의 제한된 픽셀 반짝임

문서 15장에는 공중 문서와 종이 더미로 이어지는 느슨한 전이 문서를 포함한다. 모든 프레임에서 동일한 기본 레이어를 사용하므로 개수와 종류가 변하지 않는다.

## 제외 요소

- hero 본체, 손, 지팡이 본체, 보석 본체
- dragon 본체
- 말풍선과 하단 배너
- 배경 하늘, 나무, 간판, 지면 텍스처
- 파일철, 서랍장 등 고정 배경 구조물
- 랜턴과 별도 발광 자산
- 원본에 없는 아이콘

## 프레임 변화

| 프레임 | 변화 |
|---|---|
| F1 | 원본 기준 중립 프레임 |
| F2 | 공중 흐름 `y=-1px`, 우측 UI `x=+1px, y=-1px`, 청백색 궤적 밝기 약 +8% |
| F3 | 중앙 흐름 `x=+1px`, 우측 UI 위치 중립, 궤적 밝기 약 +2% |
| F4 | 공중 흐름 `y=+1px`, 우측 UI `x=-1px, y=+1px`, 궤적 밝기 약 -6% |

- 종이 더미는 모든 프레임에서 고정했다.
- 이동은 정수 픽셀만 사용하여 안티앨리어싱이나 흐림이 생기지 않는다.
- `F4 → F1`은 1px 범위로 복귀해 튐이 크지 않다.

## 지팡이 시작점 정렬

- 승인 hero의 보석 중심은 장면 약 `(884, 422)`이다.
- paper_effect 원형 소용돌이 중심은 장면 약 `(895, 420)`이다.
- 보석 본체를 중복 포함하지 않고, 보석 앞 약 10–12px 지점에서 청백색 빛이 시작된다.
- 소용돌이의 왼쪽 가장자리와 미세 입자가 보석 앞 공간을 연결해 합성 시 단절된 틈이 보이지 않는다.

## 오브젝트 개수 유지 방식

- 한 개의 승인 기본 프레임에서 네 프레임을 파생했다.
- 프레임별 생성형 재생성을 사용하지 않았다.
- 전체 오브젝트를 삭제하거나 새로 붙이지 않고 두 넓은 영역의 1px 이동과 청백색 픽셀의 밝기 변화만 적용했다.
- 따라서 문서, 폴더, 체크, 봉투, 클립보드의 종류와 개수가 프레임마다 동일하다.

## 검수 포인트와 결과

| 항목 | 결과 |
|---|---|
| 원본과 유사한 문서·체크·폴더·봉투 구성 | 통과 |
| 프레임별 오브젝트 개수 유지 | 통과 |
| 문서와 아이콘 순간이동 없음 | 통과 |
| hero 보석 앞 시작점 연결 | 통과 |
| 마법 궤적의 기본 곡선 유지 | 통과 |
| 이동량 1px 범위 | 통과 |
| 과도한 깜빡임과 파티클 없음 | 통과 |
| 원본보다 과한 네온 발광 없음 | 통과 |
| 승인 자산과의 합성 분위기 | 통과 |
| 투명 배경과 초록 크로마 잔색 제거 | 통과 |

검수 시에는 종이 더미가 지면에서 뜨지 않는지, 보석과 소용돌이 사이가 끊기지 않는지, 우측 UI가 배경의 고정 파일철과 혼동되지 않는지를 우선 확인한다.

## magic_effect 별도 제작 판단

현재 paper_effect 안에 보석 앞 원형 소용돌이, 청백색 리본 궤적, 밝기 파동과 반짝임이 모두 포함되어 있다. 원본 장면 재현에는 별도의 `magic_effect`가 필요하지 않다. 향후 보석 자체의 국소 발광만 독립적으로 조절해야 할 경우에만 작은 gem-glow 오버레이를 별도 검토한다.

## 현재 판단

원본의 오브젝트 구성과 흐름을 충분히 재현했고 4프레임의 개수·배치 안정성이 유지된다. 현재 결과는 다음 단계로 넘길 수 있는 승인 후보로 판단한다.
